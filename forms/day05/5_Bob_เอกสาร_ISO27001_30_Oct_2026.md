**MOP-01 — ขั้นตอนปฏิบัติงาน (A.5.37)**

**ชื่องาน** กลุ่ม 02 สร้าง Ubuntu Server VM บน Proxmox VE ที่ติดตั้งอยู่แล้ว ณ Compute Node Bay 14 **อ้างอิง** CR-2569-005 **หน้าต่างเวลา** วันศุกร์ที่ 30 ตุลาคม 2569 เวลา 09:00–12:00 น. IP ของ Proxmox Host คือ 10.13.104.202; Ubuntu VM ใช้ DHCP และได้รับ IP 10.13.104.136 บัญชีผู้ใช้ Ubuntu คือ groot

เงื่อนไขยุติงาน Abort Criteria

1. ไม่สามารถเข้า Proxmox Web UI ที่ https://10.13.104.202:8006 ด้วยบัญชีที่ได้รับอนุญาต หรือเครือข่าย Management ขัดข้องและแก้ไขไม่ได้ภายใน 15 นาที
2. ไม่สามารถเปิด Console ของ Ubuntu VM หรือ Console ไม่แสดงผลต่อเนื่องเกิน 15 นาทีหลังตรวจสอบเบราว์เซอร์และสถานะ VM
3. พบ VM ID หรือชื่อ VM ที่ตั้งใจใช้ซ้ำกับระบบของกลุ่มอื่น หรือพบดิสก์/ข้อมูลเดิมที่อาจถูกเขียนทับ ให้หยุดก่อนสร้างหรือลบดิสก์
4. Storage local หรือ local-lvm ไม่มีพื้นที่เพียงพอสำหรับ Ubuntu ISO และดิสก์ VM หรือไฟล์ ISO ที่เลือกไม่สมบูรณ์
5. Proxmox Host หรือ Compute Node Bay 14 มี Fault/Critical Event หรือทรัพยากรไม่เพียงพอสำหรับ VM ใหม่
6. การตั้งค่า Bridge หรือ DHCP ทำให้ Ubuntu VM ไม่ได้รับ IP หรือเกิด IP Conflict และยังแก้ไขไม่ได้ภายในช่วงเวลาที่อนุมัติ
7. ติดตั้ง Ubuntu ไม่สำเร็จ เข้าระบบด้วยบัญชีที่กำหนดไม่ได้ หรือไม่สามารถเก็บหลักฐานผล VM ตามใบงานได้ ให้บันทึกปัญหาและแจ้งผู้ควบคุม
