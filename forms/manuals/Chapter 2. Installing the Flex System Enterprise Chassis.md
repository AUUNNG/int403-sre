# บทที่ 2: การติดตั้งแชสซีระดับองค์กร (Chapter 2. Installing the Flex System Enterprise Chassis)

เอกสารนี้แปลและเรียบเรียงจากคู่มือการติดตั้งและการบริการอย่างเป็นทางการของ Lenovo Flex System Enterprise Chassis (Lenovo Flex System Enterprise Chassis Installation and Service Guide) เพื่อใช้เป็นคู่มืออ้างอิงทางเทคนิคในการปฏิบัติงานจริง การติดตั้งในศูนย์ข้อมูล (Data Center) และการทบทวนสถาปัตยกรรมฮาร์ดแวร์

---

## 1. ภาพรวมและการจัดเตรียมการติดตั้งแชสซี (Setting up your Flex System Enterprise Chassis)

การติดตั้ง Flex System Enterprise Chassis ภายในศูนย์ข้อมูลประกอบด้วยการจัดเตรียมพื้นที่ การติดตั้งโครงสร้างตู้แร็ค (Rack) การติดตั้งอุปกรณ์ฮาร์ดแวร์ย่อยเข้าสู่โครงสร้างแชสซี และการเชื่อมต่อระบบโครงข่ายสัญญาณและพลังงานไฟฟ้า

### การเตรียมการก่อนเริ่มปฏิบัติงาน (Preparations Before You Begin)
1. **ความปลอดภัยในการทำงาน**: อ่านเอกสาร "ความปลอดภัย (Safety)" และ "การจัดการอุปกรณ์ที่ไวต่อไฟฟ้าสถิต (Handling static-sensitive devices)" อย่างละเอียดก่อนลงมือปฏิบัติงาน
2. **การตรวจสอบรายการอุปกรณ์ (Packing List Verification)**: ตรวจสอบชิ้นส่วนอุปกรณ์ทุกกล่องให้ครบถ้วนตามใบแสดงรายการบรรจุภัณฑ์ อุปกรณ์ในหนึ่งคำสั่งซื้ออาจถูกแบ่งบรรจุมาในหลายกล่อง และแต่ละกล่องอาจมีอุปกรณ์มากกว่าหนึ่งชิ้น
3. **พื้นที่ตู้แร็ค (Rack Space Requirements)**: ตรวจสอบให้แน่ใจว่ามีพื้นที่ว่างแนวตั้งต่อเนื่องกันอย่างน้อย 10 ยูนิต ($10\text{U}$) ภายในตู้แร็คสำหรับการติดตั้งแชสซี

### ขั้นตอนหลักในการตั้งค่าฮาร์ดแวร์แชสซี (Chassis Hardware Setup Tasks)
1. **การถอดชิ้นส่วนอุปกรณ์ออกจากแชสซีเพื่อลดน้ำหนัก (Removing Components)**: เพื่อความปลอดภัยในการยกติดตั้งเข้าสู่ตู้แร็ค ต้องถอดอุปกรณ์ภายในออกจากตัวถังแชสซีก่อนเสมอ (สามารถถอดชั้นวางแชสซีเพื่อลดน้ำหนักเพิ่มเติมได้ แต่ไม่จำเป็นต้องถอดโมดูลตรรกะพัดลม 2 ตัวที่อยู่ด้านหลังแชสซี)
2. **การติดตั้งโครงแชสซีลงในตู้แร็ค (Installing the Chassis in a Rack)**: ติดตั้งตัวถังแชสซีเปล่าลงบนรางรับน้ำหนักภายในตู้แร็ค
3. **การติดตั้งชิ้นส่วนอุปกรณ์กลับคืนสู่แชสซี (Reinstalling Components)**: นำอุปกรณ์ที่ถอดออกมาติดตั้งกลับเข้าไปในตำแหน่งเดิมตามลำดับที่ถูกต้อง
4. **การเดินสายสัญญาณเชื่อมต่อไปยังอุปกรณ์ภายนอก (Cabling the Chassis)**: ต่อสายสัญญาณเครือข่ายจากโมดูลต่างๆ ไปยังอุปกรณ์เครือข่ายภายนอก
5. **การเชื่อมต่อระบบไฟฟ้าเข้าสู่แชสซี (Connecting the Chassis to Power)**: เชื่อมต่อสายไฟเข้าสู่ชุดจ่ายไฟตามสถาปัตยกรรมความซ้ำซ้อน (Redundancy)

> [!IMPORTANT]
> Flex System Enterprise Chassis **ไม่มีสวิตช์เปิด-ปิดไฟหลัก (Power Switch)** บนตัวถังแชสซี การเปิดหรือตัดกระแสไฟฟ้าจะขึ้นอยู่กับการเชื่อมต่อสายไฟเข้ากับแหล่งจ่ายไฟฟ้าภายนอกโดยตรง

## 2. การถอดชิ้นส่วนอุปกรณ์เพื่อลดน้ำหนัก (Removing Components)

น้ำหนักของตัวเครื่องเมื่อติดตั้งอุปกรณ์เต็มพิกัดมีน้ำหนักสูงมาก จึงจำเป็นต้องถอดชิ้นส่วนอุปกรณ์ย่อยออกก่อนเพื่อลดน้ำหนักให้อยู่ในเกณฑ์ที่ปลอดภัยต่อการยกเคลื่อนย้ายและติดตั้งลงในตู้แร็ค

### ข้อควรระวังความปลอดภัยในการยกของหนัก (Lifting Safety & Weight Thresholds)

- **น้ำหนัก $\ge 18\text{ kg}$ ($39.7\text{ lb}$)**: ต้องใช้เจ้าหน้าที่ยกอย่างน้อย 2 คน และปฏิบัติตามแนวทางการยกของหนักอย่างปลอดภัย
- **น้ำหนัก $\ge 32\text{ kg}$ ($70.5\text{ lb}$)**: ต้องใช้เจ้าหน้าที่ยกอย่างน้อย 3 คน
- **น้ำหนัก $\ge 55\text{ kg}$ ($121.2\text{ lb}$)**: ต้องใช้เจ้าหน้าที่ยกอย่างน้อย 4 คน หรือใช้อุปกรณ์ช่วยยกเชิงกล (Mechanical Lift / Forklift)

### ขั้นตอนการถอดอุปกรณ์ด้านหน้าแชสซี (Step 1: Removing Front Components)
วางอุปกรณ์ทั้งหมดที่ถอดออกมาบนพื้นผิวราบเรียบที่มีแผ่นรองป้องกันไฟฟ้าสถิต (Static-protective Surface)
1. **อ่านคู่มือความปลอดภัย**: ศึกษาหัวข้อ "Safety" และ "Handling static-sensitive devices"
2. **ถอดโหนดประมวลผลหรือโหนดจัดเก็บข้อมูล (Compute Nodes or Storage Nodes)**:
   - สำหรับโหนดขนาด 1 ช่อง (1-bay compute node): ดึงสลักปลดล็อค (Release Latch) แล้วหมุนมือจับปลดล็อค (Release Handle) ไปทางซ้าย จากนั้นเลื่อนตัวโหนดออกจากช่องติดตั้ง (Node Bay)
   - สำหรับโหนดขนาด 2 ช่อง (2-bay compute node): ปลดและหมุนมือจับทั้งสองข้าง (มือจับซ้ายหมุนไปทางซ้าย มือจับขวาหมุนไปทางขวา) แล้วเลื่อนโหนดออกจากช่องติดตั้ง
3. **ถอดโหนดการจัดการ Flex System Manager (FSM Management Node)** (หากมีติดตั้งอยู่): ดึงสลักปลดล็อค หมุนมือจับ และดึงโหนดออกจากช่องติดตั้ง
4. **ถอดแผ่นปิดช่องและชั้นวางแชสซี (Node Bay Fillers and Chassis Shelves)**: หากต้องการลดน้ำหนักตัวถังเพิ่มเติม ให้ถอดแผ่นปิดช่องและชั้นวางแชสซีออกตามขั้นตอนการถอดชั้นวาง (Removing a chassis shelf)

### ขั้นตอนการถอดอุปกรณ์ด้านหลังแชสซี (Step 2: Removing Rear Components)
1. **ถอดชุดจ่ายไฟทั้งหมด (Power Supplies)**: ปลดสลักล็อคและดึงชุดจ่ายไฟออกจากช่องติดตั้งด้านหลัง
2. **ถอดโมดูลพัดลมขนาด 40 มม. ทั้ง 2 ตัว (40 mm Fan Modules)**: กดแท็บปลดล็อค (Release Tab) จับมือจับ (Handle) แล้วดึงโมดูลพัดลมขนาด 40 มม. ออกมา
3. **ถอดโมดูลพัดลมขนาด 80 มม. ทั้งหมด (80 mm Fan Modules)**: กดแท็บปลดล็อค จับมือจับ และดึงโมดูลพัดลมขนาด 80 มม. ออกจากช่องติดตั้ง
4. **ถอดโมดูลอินพุต/เอาต์พุตทั้งหมด (I/O Modules)**: หมุนมือจับปลดล็อค (มือจับบนหมุนขึ้น มือจับล่างหมุนลง) แล้วดึงโมดูล I/O ออกมา
5. **ถอดโมดูลการจัดการแชสซีทั้งหมด (Chassis Management Modules: CMM)**: กดสลักปลดล็อคของ CMM หมุนมือจับลงด้านล่างจนสุด แล้วดึง CMM ออกจากช่องติดตั้ง

> [!NOTE]
> ไม่จำเป็นต้องถอดโมดูลตรรกะพัดลม (Fan Logic Modules) 2 ตัวที่ติดตั้งอยู่ด้านหลังแชสซีออก

## 3. การติดตั้งแชสซีลงในตู้แร็ค (Installing the Chassis in a Rack)

การติดตั้งแชสซีต้องปฏิบัติตามข้อกำหนดความปลอดภัยของตู้แร็คอย่างเคร่งครัด โดยใช้แผ่นทาบตำแหน่งตู้แร็ค (Rack Template) และชุดอุปกรณ์ติดตั้งแร็ค (Rack Installation Kit)

### ข้อมูลความปลอดภัยของตู้แร็ค (Rack Safety Information - Statement 2 DANGER)
- **ปรับลดระดับขาตั้งของตู้แร็คเสมอ (Leveling Pads)**: ต้องหมุนปรับขาตั้งปรับระดับลงสู่พื้นห้องเพื่อความมั่นคง
- **ติดตั้งขายึดกันล้มเสมอ (Stabilizer Brackets)**: ต้องติดตั้งขายึดกันล้มเข้ากับตู้แร็คก่อนการติดตั้งอุปกรณ์
- **เริ่มติดตั้งจากด้านล่างของตู้แร็คเสมอ (Bottom-Up Principle)**: ติดตั้งเซิร์ฟเวอร์และอุปกรณ์เสริมโดยเริ่มจากยูนิตล่างสุดของตู้แร็คเสมอ
- **ติดตั้งอุปกรณ์ที่มีน้ำหนักมากที่สุดไว้ที่ด้านล่างสุดเสมอ**: อุปกรณ์ที่มีน้ำหนักมากที่สุดต้องติดตั้งอยู่ด้านล่างสุดเพื่อรักษาจุดศูนย์ถ่วง (Center of Gravity) ของตู้แร็ค ป้องกันตู้แร็คล้มคว่ำ

### ข้อกำหนดด้านสภาพแวดล้อมและตู้แร็ค (Rack Requirements)
- **อุณหภูมิห้อง**: อุณหภูมิอากาศโดยรอบห้องเซิร์ฟเวอร์ต้องต่ำกว่า $40^\circ\text{C}$ ($104^\circ\text{F}$)
- **ระยะเว้นการไหลเวียนอากาศ (Airflow Clearance)**: ห้ามปิดกั้นช่องระบายอากาศ ต้องมีช่องว่างอากาศอย่างน้อย $15\text{ cm}$ ($6\text{ in.}$) ด้านหลังตู้ และ $5\text{ cm}$ ($2\text{ in.}$) ด้านหน้าตู้
- **กำลังคนในการยกติดตั้ง**: ต้องใช้เจ้าหน้าที่อย่างน้อย 3 คนขึ้นไปในการยกอุปกรณ์เข้าสู่ตู้แร็ค
- **การปิดกั้นช่องว่างภายในตู้ (Blanking Panels / Fillers)**: ห้ามปล่อยให้มีช่องว่างที่ไม่ได้ใช้งานเปิดโล่งภายในตู้แร็ค ต้องติดตั้งแผ่นปิดช่องว่าง (Fillers) เพื่อป้องกันอากาศร้อนวนกลับมาฝั่งดูดลมเย็น (Recirculation of Warm Air)
- **ประตูตู้แร็ค**: ต้องติดตั้งแชสซีลงในตู้แร็คที่มีประตูหน้าและประตูหลังแบบเจาะรูระบายอากาศ (Perforated Doors) หรือตู้ที่ติดตั้งประตูด้านหลังแบบแลกเปลี่ยนความร้อนด้วยน้ำ (Rear Door Heat eXchanger: RDHX)
- **การเลื่อนอุปกรณ์**: ห้ามดึงอุปกรณ์ยื่นออกมานอกตู้แร็คพร้อมกันมากกว่าหนึ่งตัว
- **การถอดส่วนประกอบตู้แร็ค**: ควรถอดประตูตู้แร็คและแผงข้างออกชั่วคราวเพื่อให้ปฏิบัติงานติดตั้งได้สะดวก
- **มาตรฐานปีกเสาแร็ค**: ปีกเสาตู้แร็ค (EIA Flanges) ต้องมีขนาดรูและระยะห่างตามมาตรฐาน EIA-310-D
- **ระยะห่างระหว่างเสาหน้า-หลัง (Flange Distance)**: สำหรับตู้แร็คแบบปรับระยะได้ ให้ตั้งระยะห่างระหว่างปีกเสา EIA ด้านหน้าและด้านหลังไว้ที่ $719\text{ mm}$ ($28.3\text{ in.}$) วัดจากขอบนอกถึงขอบนอก
- **ระยะช่องว่างด้านหน้า (Front Bezel Clearance)**: ต้องมีพื้นที่ว่างด้านหน้าปีกเสา EIA ด้านหน้าอย่างน้อย $50\text{ mm}$ ($1.97\text{ in.}$) สำหรับใส่หน้ากากเครื่อง (Bezel)
- **ระยะช่องว่างด้านหลัง (Rear Cable Routing Clearance)**: ต้องมีพื้นที่ว่างเพียงพอด้านหลังปีกเสา EIA ด้านหลังสำหรับการจัดวางและเดินสายเคเบิล
- **พื้นที่ว่าง 1U สำหรับสายไฟและสายสัญญาณ (1U Service Clearance)**:
  - เว้นพื้นที่ว่าง $1\text{U}$ ที่ด้านบนสุดของตู้แร็ค หากเดินสายสัญญาณออกทางด้านบนของตู้
  - เว้นพื้นที่ว่าง $1\text{U}$ ที่ด้านล่างสุดของตู้แร็ค หากเดินสายสัญญาณออกทางด้านล่างของตู้
  - ทั้งนี้เพื่อป้องกันไม่ให้สายเคเบิลกีดขวางการถอดเปลี่ยนชิ้นส่วนอุปกรณ์ (Replaceable Components)
- **ขีดความสามารถในการรับน้ำหนัก (Weight Capacity)**: ตู้แร็คต้องสามารถรับน้ำหนักรวมของแชสซีที่ใส่อุปกรณ์ครบ, หน่วยจ่ายกำลังไฟฟ้า (Power Distribution Units: PDU) และสายไฟทั้งหมดได้
- **ความมั่นคงของตู้แร็ค**: ต้องยึดตู้แร็คด้วยขายึดกันล้มและขาปรับระดับอย่างมั่นคง ไม่ให้เกิดการโคลงเคลงเมื่อใส่อุปกรณ์เต็มตู้

- สายรัดลดแรงดึง (Strain Relief Ties): 10 เส้น

#### 2. ชุดติดตั้งตู้แร็ค (Rack Installation Kit)

### ขั้นตอนการติดตั้งแชสซีเข้าสู่ตู้แร็คทีละขั้นตอน (Step-by-Step Installation)

#### ขั้นตอนที่ 1 ถึง 6: การติดตั้งน็อตรับแรงและเตรียมราง
1. ศึกษาข้อกำหนดความปลอดภัยและวิธีการจัดการอุปกรณ์ไวต่อไฟฟ้าสถิต
2. เปิดกล่อง Rail Kit และ Rack Installation Kit ตรวจสอบรายการอุปกรณ์ให้ครบ
3. ถอดประตูตู้แร็คออกหากตู้มีประตู
4. วางแผ่นทาบตำแหน่ง (Rack Template) ทาบที่ด้านหน้าตู้แร็คในตำแหน่งที่ต้องการติดตั้ง ตรวจสอบไม่ให้ทับซ้อนกับอุปกรณ์อื่น ติดตั้งน็อตกรง M5 (สำหรับรูสี่เหลี่ยม) หรือน็อตคลิป M5 (สำหรับรูกลม) ในตำแหน่งรูที่ระบุบนแผ่นทาบ
5. วางแผ่นทาบทาบที่ด้านหลังตู้แร็ค และติดตั้งน็อตกรง M5 หรือน็อตคลิป M5 ในรูที่ระบุทุกรู (ต้องติดตั้งน็อตให้ครบทุกรูที่กำหนดบนแผ่นทาบ)
6. หดรางรองรับแชสซีทั้งสองข้างเข้าหากันให้สั้นที่สุด (Retract rails) ตรวจสอบสลักยึดราง (Rail Posts) และตะขอล็อค (Locking Hooks) ที่ปลายรางแต่ละข้าง

#### ขั้นตอนที่ 7 ถึง 8: การติดตั้งรางรองรับแชสซี
7. **ติดตั้งรางด้านหลัง**: นำรางรองรับแชสซีด้านซ้ายไปวางที่ตำแหน่งเสาด้านหลังของตู้แร็ค จัดแนวสลักบนรางให้ตรงกับรูบนปีกเสา EIA ด้านหลัง ดันสลักลอดผ่านรูจนตะขอล็อคเข้าที่ (Snap into place)
   - ขอบล่างของรางแชสซีต้องตรงกับขอบล่างของตำแหน่ง $1\text{U}$ ล่างสุดที่ต้องการให้แชสซีวางอยู่
   - หากใส่รางผิดตำแหน่ง ให้กดตัวปลดตะขอล็อค (Locking Hooks Release) เพื่อปลดตะขอ แล้วเลื่อนสลักออกจากรูเพื่อจัดตำแหน่งใหม่
   - ตรวจสอบให้แน่ใจว่าสลักของรางยื่นทะลุผ่านรูของปีกเสา EIA ออกมาอย่างชัดเจน
8. **ติดตั้งรางด้านหน้า**: ดึงรางแชสซีไปข้างหน้า สอดสลักด้านหน้ารางเข้ากับรูของปีกเสา EIA ด้านหน้าจนล็อคเข้าที่ ทำซ้ำขั้นตอนที่ 6 ถึง 8 สำหรับรางด้านขวา

#### ขั้นตอนที่ 9: การยึดรางด้วยสกรู
9. ใช้สกรูหัวผสมสีดำ M5x16 ยึดรางเข้ากับปีกเสา EIA:
   - ด้านหน้าตู้แร็ค: ขันสกรู M5x16 สีดำเข้าที่รูเกลียวตัวล่าง (Lower Threaded Hole) ที่ด้านหน้าของรางแต่ละข้าง (ข้างละ 1 ตัว รวม 2 ตัว)
   - ด้านหลังตู้แร็ค: ขันสกรู M5x16 สีดำเข้าที่รูเกลียวตัวบน (Upper Threaded Hole) ที่ด้านหลังของรางแต่ละข้าง (ข้างละ 1 ตัว รวม 2 ตัว)
   - ขันสกรูยึดรางทั้งด้านหน้าและด้านหลังให้แน่นด้วยแรงบิด **$30\text{ in-lbs}$ ($3.4\text{ Nm}$)**

#### ขั้นตอนที่ 10 ถึง 13: การยกแชสซีเข้าสู่ตู้แร็ค
10. ตรวจสอบให้แน่ใจว่าได้ถอดชิ้นส่วนภายในแชสซีออกเพื่อลดน้ำหนักแล้ว
11. ติดตั้งหูจับสำหรับยกแชสซี (Chassis Handles) จำนวน 4 ตัวเข้ากับด้านข้างของแชสซี จัดแนวช่องบนหูจับให้ตรงกับสลักที่ด้านข้างตัวถังแชสซี แล้วเลื่อนหูจับขึ้นด้านบนจนล็อคเข้าที่
12. ยกตัวถังแชสซีขึ้น วางส่วนท้ายของแชสซีลงบนรางรองรับ แล้วดันแชสซีเข้าไปในตู้แร็คจนกระทั่งหูจับคู่หลังอยู่ใกล้กับปีกเสา EIA ด้านหน้า ขณะที่ช่วยกันพยุงแชสซีไว้ ให้ถอดหูจับคู่หลังออกทั้งสองข้าง โดยกดสลักสปริง (Spring-latches) บนหูจับเข้าด้านในแล้วเลื่อนหูจับลงด้านล่างเพื่อถอดออก
13. ดันแชสซีลึกเข้าไปในตู้แร็คจนหูจับคู่หน้ามาอยู่ใกล้กับปีกเสา EIA ด้านหน้า แล้วถอดหูจับคู่หน้าออกทั้งสองข้าง จากนั้นเลื่อนแชสซีเข้าไปจนสุดตู้แร็ค

#### ขั้นตอนที่ 14: การติดตั้งขายึดเสริมด้านหลัง (สำหรับการขนส่ง)
14. หากมีแผนจะขนย้ายตู้แร็คไปยังสถานที่อื่นพร้อมกับแชสซีที่ติดตั้งอยู่ภายใน ต้องติดตั้งขายึดรองรับด้านหลัง (Rear Support Brackets) เพิ่มเติม:
    - จัดแนวขายึดด้านหลังซ้าย (Left Support Bracket) ให้ตรงกับช่องสล็อต 4 ช่องที่ด้านนอกของแชสซี
    - เลื่อนขายึดไปข้างหน้าจนล็อคเข้าช่องสล็อต
    - ติดตั้งสกรูหัวผสมสีดำ M5x16 จำนวน 3 ตัวเพื่อยึดขายึดเข้ากับตู้แร็ค (ขันพอหลวม ยังไม่ต้องขันแน่น)
    - ทำซ้ำแบบเดียวกันสำหรับขายึดด้านหลังขวา (Right Support Bracket)
    - ติดตั้งขายึดด้านล่าง (Lower Support Bracket) เข้าที่ใต้ตัวถังแชสซี เลื่อนขายึดไปข้างหน้าจนชิดกับตู้แร็ค
    - ขันสกรู M5x16 สีดำจำนวน 4 ตัวเข้ากับขายึดด้านล่าง (ข้างขวา 2 ตัว ข้างซ้าย 2 ตัว ขันพอหลวม)
    - เมื่อติดตั้งขายึดและสกรูครบทุกชิ้นแล้ว ให้ขันสกรูทั้งหมดให้แน่นด้วยแรงบิด **$30\text{ in-lbs}$ ($3.4\text{ Nm}$)**

#### ขั้นตอนที่ 15 ถึง 20: การยึดแชสซีด้านหน้าและการประกอบชิ้นส่วนคืน
15. ถอดแผ่นป้ายพลาสติก (Plastic Label Plates) ออกจากด้านซ้ายและขวาของแชสซี
16. ขันสกรูพร้อมแหวนรองในตัวสีเงิน ขนาด M5x16 จำนวน 8 ตัว ผ่านรูด้านหน้าของแชสซีเข้ากับเสาแร็ค (ฝั่งละ 4 ตัว) ขันพอหลวม
17. ขันสกรูทั้ง 8 ตัวให้แน่นด้วยแรงบิด **$30\text{ in-lbs}$ ($3.4\text{ Nm}$)**
18. ติดตั้งแผ่นป้ายพลาสติกกลับคืนเข้าที่ด้านซ้ายและด้านขวาของแชสซี
19. ติดตั้งชั้นวางแชสซี (Chassis Shelves) กลับคืน หากถอดออกไปก่อนหน้า
20. ติดตั้งชิ้นส่วนอุปกรณ์ทั้งหมดกลับคืนสู่ตัวถังแชสซี

## 4. การติดตั้งชิ้นส่วนอุปกรณ์กลับคืนสู่แชสซี (Installing Components)

(80 mm Fan Modules) เข้าสู่ Flex System Enterprise Chassis **ต้องเริ่มติดตั้งจากช่องด้านล่างขึ้นสู่ด้านบนเสมอ** เพื่อรักษาความสมดุลและการกระจายน้ำหนักของระบบ

### ลักษณะการใช้งานช่องติดตั้งของโหนดประเภทต่างๆ
- **โหนดประมวลผลขนาด 1 ช่อง (1-Bay Compute Node)**: ใช้พื้นที่ 1 ช่องติดตั้งในแชสซี
- **โหนดประมวลผลขนาด 1 ช่อง พร้อมโมดูลขยาย (1-Bay with Captive-Mode Expansion Node)**: ใช้พื้นที่ 2 ช่องติดตั้งที่อยู่ติดกันในแนวนอน (ต้องถอดชั้นวางแชสซีกั้นกลางออกก่อนติดตั้ง)
- **โหนดประมวลผลขนาด 2 ช่อง (2-Bay Compute Node)**: ใช้พื้นที่ 2 ช่องติดตั้งที่อยู่ติดกันในแนวนอน (ต้องถอดชั้นวางแชสซีกั้นกลางออกก่อนติดตั้ง)
- **กล่องอุปกรณ์จัดเก็บข้อมูลขนาด 4 ช่อง (4-Bay Storage Enclosure)**: ใช้พื้นที่ 4 ช่องติดตั้งที่อยู่ติดกัน (2 ช่องในแนวตั้ง และ 2 ช่องในแนวนอน ต้องถอดชั้นวางแชสซีและแกนค้ำชั้นวางตรงกลางออกก่อนติดตั้ง)

### ข้อกำหนดชุดจ่ายไฟ (Power Supplies Requirements)

โหลดพลังงานไฟฟ้าของแชสซีขึ้นอยู่กับจำนวนและประเภทของโหนดประมวลผล, โหนดจัดเก็บข้อมูล, โมดูล I/O และโมดูลการจัดการที่ติดตั้ง สามารถใช้เครื่องมือ Lenovo Capacity Planner ในการคำนวณโหลดไฟฟ้าได้อย่างแม่นยำ

#### กฎสำคัญในการติดตั้งชุดจ่ายไฟ:
- ติดตั้งได้สูงสุด 6 ตัว
- **ห้ามติดตั้งชุดจ่ายไฟต่างประเภทปนกัน** ภายในแชสซีเดียวกัน
- แต่ละแชสซีต้องใช้ระบบไฟฟ้ากระแสสลับ (AC) ทั้งหมด หรือระบบไฟฟ้ากระแสตรง (DC) ทั้งหมดเท่านั้น
- สำหรับแชสซีระบบไฟฟ้ากระแสสลับ (AC) **ห้ามใช้ชุดจ่ายไฟขนาด $2100\text{ W}$ ปะปนกับชุดจ่ายไฟขนาด $2500\text{ W}$** ชุดจ่ายไฟทุกตัวในแชสซีต้องมีกำลังวัตต์เท่ากันทั้งหมด
- ลำดับการติดตั้งจากล่างขึ้นบน: เริ่มจากช่องเสียบชุดจ่ายไฟ 1 และ 4 ก่อน, ตามด้วยช่องเสียบ 2 และ 5, และปิดท้ายด้วยช่องเสียบ 3 และ 6

#### ตารางที่ 6: จำนวนชุดจ่ายไฟที่ต้องติดตั้งสัมพันธ์กับจำนวนช่องโหนดที่ใช้งาน (Table 6)

| จำนวนช่องโหนดที่ติดตั้งใช้งาน (Number of Populated Node Bays) | จำนวนชุดจ่ายไฟที่ต้องติดตั้ง (Power Supplies Required) |
| :---: | :---: |
| 1 ถึง 4 ช่อง | 2 ชุด |
| 5 ถึง 6 ช่อง | 3 ชุด |
| 7 ถึง 8 ช่อง | 4 ชุด |
| 9 ถึง 11 ช่อง | 5 ชุด |
| 12 ถึง 14 ช่อง | 6 ชุด |

### ข้อกำหนดโมดูลพัดลมระบายความร้อนขนาด 80 มม. (80 mm Fan Modules Requirements)

จำนวนและประเภทของพัดลมขนาด 80 มม. ขึ้นอยู่กับประเภทของชุดจ่ายไฟและจำนวนโหนดที่ติดตั้งในแชสซี สามารถติดตั้งได้สูงสุด 8 ตัว

#### กฎสำคัญในการติดตั้งโมดูลพัดลม:
- แชสซีที่ใช้ชุดจ่ายไฟ $2100\text{ W}$ ต้องใช้โมดูลพัดลมขนาด 80 มม. **แบบพัดลมเดี่ยว (Single-fan Modules)**
- แชสซีที่ใช้ชุดจ่ายไฟ $2500\text{ W}$ ต้องใช้โมดูลพัดลมขนาด 80 มม. **แบบพัดลมคู่ (Dual-fan Modules)**
- ต้องใช้โมดูลพัดลมชนิดเดียวกันทั้งหมดภายในแชสซี ห้ามผสมพัดลมเดี่ยวและพัดลมคู่ร่วมกัน

### ขั้นตอนการติดตั้งโหนดประมวลผล (Compute Nodes Installation Procedures)

#### 1. การติดตั้งโหนดประมวลผลขนาด 1 ช่อง (1-Bay Compute Node)
ติดตั้งได้สูงสุด 14 โหนดที่ด้านหน้าแชสซี:
1. ปลดแผ่นปิดช่องโหนด (Node Bay Filler): ดันแท็บปลดล็อคไปทางขวา แล้วจับช่องสล็อตดึงแผ่นปิดช่องออกมา
2. เปิดมือจับปลดล็อค (หมุนมือจับไปทางซ้าย)
3. เลื่อนโหนดประมวลผลเข้าไปในช่องติดตั้งจนกระทั่งเข้าล็อคสนิท
4. ปิดมือจับปลดล็อค (หมุนมือจับไปทางขวา)
5. บันทึกข้อมูลระบุตัวตนของโหนดลงบนป้ายระบุ (User Label ขนาด 1) ติดที่แถบป้ายของโหนดและบนแผ่นป้ายแชสซีที่อยู่ติดกัน (ห้ามติดป้ายทับช่องระบายอากาศ)

#### 2. การติดตั้งโหนดประมวลผลขนาด 2 ช่อง (2-Bay Compute Node)
ติดตั้งได้สูงสุด 7 โหนด:
1. เลือกช่องติดตั้ง 2 ช่องที่อยู่ติดกันในแนวนอน
2. ถอดแผ่นปิดช่องและถอดชั้นวางแชสซีที่คั่นระหว่าง 2 ช่องนั้นออก
3. เปิดมือจับปลดล็อคทั้งสองข้าง (หมุนมือจับซ้ายไปทางซ้าย หมุนมือจับขวาไปทางขวา)
4. เลื่อนโหนดเข้าไปในช่องติดตั้งจนกระทั่งเข้าล็อคสนิท
5. ปิดมือจับปลดล็อคทั้งสองข้างกลับเข้าที่เดิม

#### 3. การติดตั้งกล่องจัดเก็บข้อมูลขนาด 4 ช่อง (4-Bay Storage Enclosure)
1. เลือกช่องติดตั้ง 4 ช่องที่อยู่ติดกัน (2 ช่องแนวตั้ง และ 2 ช่องแนวนอน)
2. ถอดแผ่นปิดช่อง ชั้นวางแชสซี และแกนค้ำชั้นวางตรงกลาง (Shelf Supports) ออกทั้งหมด
3. ติดตั้งกล่องจัดเก็บข้อมูลและต่อสายสัญญาณตามคู่มือเฉพาะของ Storage Enclosure

### การติดตั้งโมดูลการจัดการแชสซี (Chassis Management Module: CMM)

สามารถติดตั้ง CMM ได้สูงสุด 2 ตัวเพื่อการทำงานแบบสำรองความพร้อมใช้งานสูง (Redundancy):
1. หากมีแผ่นปิดช่อง CMM ให้ถอดออก โดยหมุนมือจับลงด้านล่างแล้วดึงออก
2. กดสลักปลดล็อคของ CMM แล้วหมุนมือจับ CMM ลงด้านล่างจนสุด
3. จัดแนว CMM ให้ตรงกับช่องติดตั้งแล้วเลื่อนเข้าไปจนสุด
4. ปิดมือจับ (หมุนมือจับขึ้นด้านบน) จนกระทั่งล็อคเข้าที่
5. ตรวจสอบว่าไฟแสดงสถานะการเปิดเครื่อง (Power-on LED) สว่างขึ้น แสดงว่า CMM ทำงานปกติ

> [!WARNING]
> **ข้อควรระวังเรื่องการตั้งค่าเครือข่ายของ CMM:**
> - หากเครือข่ายไม่มีระบบจ่ายไอพีอัตโนมัติ (DHCP Server) CMM จะต้องใช้เวลาสูงสุด **3 นาที** ในการเปลี่ยนไปใช้ IP Address ปริยายแบบคงที่ (Default Static IP)
> - เมื่อเกิดการสลับการทำงานอัตโนมัติ (Failover) ระหว่าง CMM คู่สำรอง อาจต้องรอเวลานานถึง **5 นาที** ในการสร้างการเชื่อมต่อเครือข่ายใหม่ เนื่องจากสวิตช์และเราเตอร์บางรุ่นไม่ได้รีเลย์แพ็กเก็ต ARP เพื่ออัปเดตตาราง Address Resolution Protocol (ARP Table) ทันที ส่งผลให้การจับคู่ MAC Address กับ IP ใหม่ยังไม่ถูกต้องจนกว่าตาราง ARP เดิมจะหมดอายุ (Timeout) แนะนำให้กำหนดค่าเราเตอร์ให้ยอมรับและรีเลย์แพ็กเก็ต ARP จาก CMM

### การติดตั้งโหนดการจัดการ Flex System Manager (FSM Management Node)

สามารถติดตั้ง FSM Management Node ได้สูงสุด 2 โหนดในโครงสร้างแบบหลายแชสซี (Multiple-chassis Configuration) เพื่อการสำรองระบบ:

> [!CAUTION]
> **ข้อควรระวังเรื่อง IP ชนกัน (IP Conflict Warning):**
> ค่า IP Address ปริยายแบบคงที่ (Default Static IP) ของโหนดการจัดการจะขึ้นอยู่กับ **หมายเลขช่องติดตั้ง (Node Bay Number)** หากติดตั้งโหนดการจัดการในระบบหลายแชสซี **ห้ามติดตั้งโหนดการจัดการในหมายเลขช่องเดียวกันข้ามแชสซีเด็ดขาด** (เช่น หากแชสซีแรกติดตั้งที่ Bay 1 แชสซีที่สองต้องติดตั้งในช่องอื่นที่ไม่ใช่ Bay 1) ไม่เช่นนั้นโหนดทั้งสองจะมี IP Address ปริยายซ้ำกัน ทำให้ระบบเครือข่ายขัดข้อง

### การติดตั้งชุดจ่ายไฟและการต่อสายดิน (Power Supply & DC Ground Installation)

แชสซีจะมาพร้อมชุดจ่ายไฟติดตั้งล่วงหน้า 2 ตัวที่ด้านหลัง สามารถติดตั้งเพิ่มได้อีก 4 ตัว รวมเป็น 6 ตัว:
1. ถอดแผ่นปิดช่องชุดจ่ายไฟออก
2. จับมือจับของชุดจ่ายไฟและเลื่อนเข้าไปในช่องติดตั้งจนล็อคเข้าที่
3. **สำหรับการติดตั้งชุดจ่ายไฟระบบไฟฟ้ากระแสตรง ($-48\text{ V}$ ถึง $-60\text{ V DC}$)**:
   - ใช้บล็อกขันน็อตขนาด $10\text{ mm}$ (10 mm Nut Driver) ถอดน็อตหกเหลี่ยมออกจากสลักต่อสายดิน (Ground Studs)
   - ถอดแหวนสปริง (Lock Washer) และแหวนรองเรียบ (Flat Washer) ออกหนึ่งตัว
   - สวมหางปลาสายดิน (Ground Lug) เข้ากับสลักสายดิน จากนั้นใส่แหวนรองเรียบ, แหวนสปริง และน็อตหกเหลี่ยมกลับคืน
   - ใช้บล็อกขันน็อต $10\text{ mm}$ ขันน็อตให้แน่นด้วยแรงบิด **$4.0$ ถึง $4.8\text{ Nm}$ ($35.4$ ถึง $42.5\text{ in-lbs}$)**
4. **การต่อสายไฟและการลดแรงดึง (Strain-relief Ties)**:
   - คลายสายรัดลดแรงดึงที่ติดอยู่กับมือจับของชุดจ่ายไฟ (ไม่ต้องดึงสายรัดออก)
   - จัดแนวสายไฟให้ขนานกับมือจับ แล้วรัดสายไฟให้แน่นด้วยสายรัดลดแรงดึง
   - โค้งปลายสายไฟและเสียบขั้วต่อเข้ากับชุดจ่ายไฟ
   - ดันสายไฟย้อนกลับผ่านสายรัดเพื่อลดขนาดห่วงสายไฟส่วนเกินให้เรียบร้อย

### การติดตั้งโมดูลพัดลมขนาด 80 มม. (80 mm Fan Module Installation)
1. ถอดแผ่นปิดช่องพัดลมออก
2. จับมือจับของโมดูลพัดลมและจัดแนวให้ตรงกับช่องติดตั้ง
3. เลื่อนโมดูลพัดลมเข้าไปจนกระทั่งล็อคเข้าที่

### การติดตั้งโมดูลรับส่งข้อมูล (I/O Module Installation)

ติดตั้งได้สูงสุด 4 โมดูลที่ด้านหลังแชสซี:
- **ข้อกำหนด I/O Bay 1 และ Bay 2**: จะต้องติดตั้งสวิตช์อีเทอร์เน็ต (Ethernet Switch) หรือโมดูลส่งผ่านสัญญาณ (Pass-thru Module) ในช่อง I/O Bay 1 และ/หรือ Bay 2 เสมอ เมื่อมีการเปิดใช้งานพอร์ตอีเทอร์เน็ตบนเมนบอร์ดของโหนดประมวลผล หรือมีการติดตั้งการ์ดเชื่อมต่อเครือข่ายอีเทอร์เน็ต (Ethernet I/O Expansion Card) ที่เชื่อมโยงกับ Bay 1 และ Bay 2
- **ขั้นตอนการติดตั้ง**:
  1. ถอดแผ่นปิดช่อง I/O ออก (หมุนมือจับบนขึ้น มือจับล่างลง แล้วดึงออก)
  2. เปิดมือจับของโมดูล I/O (หมุนมือจับบนขึ้น มือจับล่างลง)
  3. เลื่อนโมดูลเข้าสู่ช่องติดตั้งจนสนิท
  4. ปิดมือจับ (หมุนมือจับบนลง มือจับล่างขึ้น) จนล็อคแน่นหนา

## 5. การผสานรวมระบบเครือข่ายเข้ากับ Flex System Manager (Network Integration with Flex System Manager)

การออกแบบเครือข่ายของ Flex System Enterprise Chassis สามารถแยกเครือข่ายออกเป็น 2 ส่วนชัดเจน เพื่อความปลอดภัยและประสิทธิภาพสูงสุด:

```
                                  สถาปัตยกรรมการแยกเครือข่าย
                       (Example of Separate Management and Data Networks)

       +---------------------------------------------------------------------------------+
       | Enterprise Chassis                                                              |
       |                                                                                 |
       |  +--------------------------+       +-------------------+  +-----------------+  |
       |  | IBM Flex System Manager  |       |      Node 1       |  |     Node 2      |  |
       |  |                          |       +-------------------+  +-----------------+  |
       |  |     Eth0        Eth1     |                 |                      |          |
       |  +-------+-----------+------+                 |                      |          |
       |          |           |                        |                      |          |
       |          v           +-----------+            |                      |          |
       |      +-------+                   |            |                      |          |
       |      |  CMM  |                   v            v                      v          |
       |      +---+---+               +-------------------------------------------+      |
       |          |                   |          I/O Bay 1  /  I/O Bay 2          |      |
       +----------|-------------------+--------------------+----------------------+------+
                  |                                        |
                  v                                        v
       +--------------------+                    +--------------------+
       | Top-of-Rack Switch |                    |    Data Network    |
       +---------+----------+                    +--------------------+
                 |
                 v
       +--------------------+
       | Management Network |
       +--------------------+
```

### 1. เครือข่ายการจัดการ (Management Network)
- ใช้งานผ่านพอร์ต **Eth0** ของโหนดการจัดการ FSM ซึ่งเชื่อมต่อไปยังพอร์ต Ethernet ภายนอกของ CMM ผ่านโครงข่ายการจัดการภายในแชสซี
- CMM เชื่อมต่อไปยังสวิตช์ประจำตู้ (Top-of-Rack Switch) เพื่อเป็นศูนย์กลางการบริหารจัดการฮาร์ดแวร์ทุกชิ้นผ่านซอฟต์แวร์ Flex System Manager
- **ข้อกำหนดความปลอดภัย**: การรับส่งข้อมูลการจัดการทั้งหมด (CMM, IMM, FSP และหน้าคอนฟิกสวิตช์) **ต้องอยู่บนคนละ Subnet/VLAN กับทราฟฟิกข้อมูลการทำงานจริง (Production Data Traffic)** ห้ามอยู่บน Subnet เดียวกัน

### 2. เครือข่ายข้อมูล (Data Network)
- ใช้งานผ่านพอร์ต **Eth1** ของโหนดการจัดการ FSM ซึ่งเชื่อมต่อเข้ากับสวิตช์โมดูลใน I/O Bay 1 หรือ Bay 2
- ใช้สำหรับการส่งข้อมูลของระบบปฏิบัติการและแอปพลิเคชัน รองรับความเร็วสูงสุด $10\text{ Gbps}$
- รองรับฟังก์ชันการค้นหาระบบปฏิบัติการ (OS Discovery) บนอุปกรณ์ปลายทางเพื่อการอัปเดตแพตช์ซอฟต์แวร์
- ใช้ในการทำสำเนาข้อมูลความเร็วสูงระหว่าง FSM โหนดหลัก (Active) และโหนดสำรอง (Passive) ในระบบ High-availability

### สถาปัตยกรรมเครือข่ายแบบรวม (Single Network Configuration)
- กำหนดค่าให้ Management Network และ Data Network อยู่บนระบบเครือข่ายเดียวกัน โดยคอนฟิกเฉพาะพอร์ต Eth0
- ติดตั้งง่ายและซับซ้อนน้อยกว่า แต่มีข้อเสียร้ายแรงด้านความมั่นคงปลอดภัย เพราะผู้ใช้และแอปพลิเคชันทั่วไปในเครือข่ายข้อมูลจะสามารถเข้าถึงเครือข่ายการจัดการได้ จึงไม่แนะนำสำหรับระบบที่ต้องการความปลอดภัยสูง

## 6. การเชื่อมต่อระบบไฟฟ้าเข้าสู่แชสซี (Connecting the Chassis to Power)

การเชื่อมต่อระบบไฟฟ้าเข้าสู่ Flex System Enterprise Chassis ต้องคำนวณและเลือกสถาปัตยกรรมความซ้ำซ้อนให้เหมาะสมกับระดับความต่อเนื่องในการดำเนินงาน (Business Continuity)

### 1. การต่อไฟแบบสำรองแหล่งจ่ายไฟคู่ ($N+N\text{ Power Redundancy}$)
- รองรับชุดจ่ายไฟสูงสุด 6 ตัว โดยแบ่งออกเป็น $N+N$ ($N$ อาจเป็น 1, 2 หรือ 3 ขึ้นอยู่กับโหลดรวมของอุปกรณ์ในแชสซี)
- เชื่อมต่อสายไฟของชุดจ่ายไฟแยกออกเป็น 2 วงจร ไปยัง PDU คนละตัวกัน (เช่น 3 ตัวแรกต่อ PDU A และ 3 ตัวหลังต่อ PDU B)
- หากวงจรไฟฟ้าหรือ PDU ตัวใดตัวหนึ่งดับทั้งหมด ชุดจ่ายไฟที่เหลือยังคงมีกำลังไฟฟ้าเพียงพอที่จะรองรับโหลดของทั้งแชสซีได้อย่างต่อเนื่อง
- การทำงานแบบ $N+N$ เต็มรูปแบบสำหรับแชสซีที่ใส่อุปกรณ์เต็มพิกัดจะใช้ชุดจ่ายไฟครบทั้ง 6 ตัว

```
สถาปัตยกรรม N+N Redundancy:
+-------------------+       +-------------------+
|       PDU A       |       |       PDU B       |
+-------------------+       +-------------------+
  |       |       |           |       |       |
  v       v       v           v       v       v
[PSU 1] [PSU 2] [PSU 3]     [PSU 4] [PSU 5] [PSU 6]
```

### 2. การต่อไฟแบบสำรองชุดจ่ายไฟ ($N+1\text{ Power Redundancy}$)
- ใช้งานในกรณีที่ไม่ได้กังวลเรื่องแหล่งจ่ายไฟหลักดับ แต่ต้องการป้องกันกรณีชุดจ่ายไฟตัวใดตัวหนึ่งเสียหาย ($N$ อาจเป็น 1, 2, 3, 4 หรือ 5)
- สายไฟของชุดจ่ายไฟทุกตัวเชื่อมต่อเข้ากับ **PDU ตัวเดียวกันทั้งหมด** โดยมีชุดจ่ายไฟสำรองเผื่อไว้ 1 ตัว ($+1$)
- หากชุดจ่ายไฟเสียหาย 1 ตัว ระบบจะยังทำงานต่อได้ แต่หาก PDU ดับ หรือไฟต้นทางขัดข้อง แชสซีจะดับลงทั้งหมดทันที

```
สถาปัตยกรรม N+1 Redundancy:
+-------------------------------------------------------+
|                         PDU                           |
+-------------------------------------------------------+
    |               |               |               |
    v               v               v               v
 [PSU 1]         [PSU 2]         [PSU 3]         [PSU 4 (+1)]
```

> [!CAUTION]
> หากกำลังไฟฟ้าของชุดจ่ายไฟที่ติดตั้งไม่เพียงพอต่อโหลดรวมของอุปกรณ์ภายใน CMM จะไม่อนุญาตให้อุปกรณ์บางตัวเปิดทำงาน

### ข้อควรระวังความปลอดภัยทางไฟฟ้าขั้นวิกฤต (Electrical Safety Statements)

#### Statement 29 & Statement 31: อันตรายจากกระแสไฟฟ้า (DANGER)
- กระแสไฟฟ้าจากสายไฟหลัก, สายโทรศัพท์ และสายสื่อสารเป็นอันตรายถึงชีวิต
- ห้ามเชื่อมต่อหรือถอดสายสัญญาณใดๆ ในระหว่างเกิดพายุฝนฟ้าคะนอง (Electrical Storm)
- ต้องเชื่อมต่อสายไฟเข้ากับเต้ารับที่มีการเดินสายและต่อลงกราวด์อย่างถูกต้องเท่านั้น
- เมื่อเป็นไปได้ ให้ใช้มือเพียงข้างเดียวในการเสียบหรือถอดสายสัญญาณ (One-Hand Rule) เพื่อป้องกันกระแสไฟไหลผ่านหัวใจ
- ห้ามเปิดใช้งานอุปกรณ์เด็ดขาดหากพบร่องรอยความเสียหายจากไฟไหม้ น้ำ หรือความเสียหายเชิงโครงสร้าง

#### ตารางลำดับการเชื่อมต่อและการตัดการเชื่อมต่อระบบไฟฟ้า (Connection & Disconnection Protocol)

| ลำดับขั้นตอนการเชื่อมต่อสาย (To Connect) | ลำดับขั้นตอนการตัดการเชื่อมต่อสาย (To Disconnect) |
| :--- | :--- |
| 1. **ปิดสวิตช์ (Turn OFF)** แหล่งจ่ายไฟและอุปกรณ์ทั้งหมดที่จะเชื่อมต่อ | 1. **ปิดสวิตช์ (Turn OFF)** แหล่งจ่ายไฟและอุปกรณ์ทั้งหมดที่เชื่อมต่อ |
| 2. เชื่อมต่อสายสัญญาณเข้ากับตัวอุปกรณ์ | - สำหรับระบบ AC: ถอดสายไฟทั้งหมดออกจากเต้ารับแชสซี หรือตัดไฟที่ PDU |
| 3. เชื่อมต่อสายไฟเข้ากับตัวอุปกรณ์:<br>- ระบบ AC: เสียบเข้ากับช่องรับไฟของตัวเครื่อง<br>- ระบบ DC: ตรวจสอบขั้วไฟฟ้า $-48\text{ V DC}$ ให้ถูกต้อง (RTN คือขั้วบวก $+$ และ $-48\text{ V DC}$ คือขั้วลบ $-$) และใช้หางปลาแบบ 2 รูสำหรับสายดิน | - สำหรับระบบ DC: ปลดวงจรไฟฟ้าที่แผงเบรกเกอร์ หรือปิดแหล่งจ่ายไฟ แล้วจึงถอดสายไฟ DC ออก |
| 4. เชื่อมต่อสายสัญญาณเข้ากับอุปกรณ์ภายนอก | 2. ถอดสายสัญญาณออกจากขั้วต่อ |
| 5. เชื่อมต่อสายไฟเข้ากับแหล่งจ่ายไฟฟ้าภายนอก | 3. ถอดสายเคเบิลทั้งหมดออกจากอุปกรณ์ |
| 6. **เปิดสวิตช์ (Turn ON)** แหล่งจ่ายไฟทั้งหมด | |

### ข้อกำหนดทางเทคนิคสำหรับระบบไฟฟ้ากระแสตรง $-48\text{ V DC}$ (Statement 34)

- ต้องติดตั้งโดยช่างบริการผู้เชี่ยวชาญเฉพาะทางในสถานที่จำกัดการเข้าถึง (Restricted-access Location) ตามมาตรฐาน NEC และ IEC 60950-1
- ต้องเชื่อมต่ออุปกรณ์เข้ากับแหล่งจ่ายไฟความปลอดภัยแรงดันต่ำพิเศษ (Safety Extra Low Voltage: SELV) โดยมีแรงดันไม่เกิน $60\text{ V DC}$
- ต้องใช้นำสายไฟที่เป็นตัวนำทองแดงเท่านั้น (Copper Wire Only)

#### ตารางพิกัดเบรกเกอร์และสายดินสำหรับชุดจ่ายไฟ $-48\text{ V DC}$

| รายการอุปกรณ์ | พิกัดที่กำหนด (Specification) | ข้อกำหนดเพิ่มเติม |
| :--- | :--- | :--- |
| **เบรกเกอร์วงจรไฟฟ้า (Circuit Breaker)** | พิกัดรับรองตามรายการ (Listed) ขนาด **$70\text{ A}$** | แม้กระแสสถิตต่อเนื่องสูงสุดจะต่ำกว่า $70\text{ A}$ แต่ในช่วงเกิดภาวะ Over Subscription อุปกรณ์อาจดึงกระแสชั่วขณะเกินกว่า $70\text{ A}$ แนะนำให้ใช้เบรกเกอร์ที่รองรับกระแสได้ถึง **$90\text{ A}$ เป็นเวลาอย่างน้อย $20\text{ ms}$** เช่น แผงกระจายกำลัง Telect Dual 350A (P/N 350CB06) ร่วมกับเบรกเกอร์ Telect 70A (P/N 090-0052-0070) |
| **สายดิน (Ground Cable)** | ขนาด **$4\text{ AWG}$** พร้อมหางปลามาตรฐานรองรับน็อต M6 | หากไม่ได้เชื่อมต่อเข้ากับแหล่งจ่ายไฟ SELV ที่มีฉนวนเสริมแรง (Reinforced Insulation) ต้องติดตั้งสายดินเสมอ |
| **ค่าแรงบิดขันน็อตสายดิน** | **$4.0$ ถึง $4.8\text{ Nm}$** ($35.4$ ถึง $42.5\text{ in-lbs}$) | ใช้บล็อกขันน็อตขนาด $10\text{ mm}$ |

### ขั้นตอนการเชื่อมต่อสายไฟและการตรวจสอบสถานะ
1. **สำหรับแชสซีระบบไฟฟ้ากระแสสลับ (AC-powered)**: เสียบสายไฟเข้ากับ PDU, UPS หรือเต้าเสียบผนังที่รองรับเบรกเกอร์ไม่เกิน $20\text{ A}$ (หรือสายไฟพิเศษ Flex System 3X Power Cord ที่รองรับเต้าเสียบผนังสูงสุด $32\text{ A}$)
2. **สำหรับแชสซีระบบไฟฟ้ากระแสตรง (DC-powered)**: ต่อสายดินเข้ากับชุดจ่ายไฟด้วยแรงบิด $4.0$ ถึง $4.8\text{ Nm}$ แล้วต่อสายไฟ DC เข้ากับตู้ DC PDU
3. **ตรวจสอบไฟแสดงสถานะ (LED Status Verification)**:
   - โลโก้บนแผงแสดงข้อมูลด้านหน้าแชสซี (Chassis Front Information Panel) ต้องสว่าง
   - ไฟสถานะ DC Power และ AC Power บนชุดจ่ายไฟแต่ละตัวต้องสว่าง
   - ไฟสถานะ Power บนโมดูล I/O แต่ละโมดูลต้องสว่าง
   - ไฟสถานะ Power บนโหนดประมวลผลและโหนด FSM จะกระพริบช้าๆ เพื่อแสดงว่าได้รับไฟเลี้ยงและพร้อมเปิดทำงาน
4. **หากไฟสถานะไม่สว่าง**: ให้ตัดการเชื่อมต่อระบบไฟฟ้า ขยับและดันอุปกรณ์ทุกชิ้นในแชสซีให้เข้าล็อคใหม่อีกครั้ง (Reseat Components) แล้วต่อสายไฟกลับเข้าไป หากปัญหายังไม่หายให้ติดต่อฝ่ายสนับสนุนทางเทคนิค

## 7. การติดป้ายระบุข้อมูลอุปกรณ์ของผู้ใช้ (User Labels)

เพื่อการบริหารจัดการและการบำรุงรักษาที่มีประสิทธิภาพ แชสซีจะมาพร้อมชุดป้ายเปล่าสำหรับบันทึกข้อมูล:
- **ป้ายขนาดใหญ่ (Size 1)**: ใช้ติดบนแถบป้ายประจำโหนด (Node Label Tab) และติดบนแผ่นป้ายประจำแชสซี (Chassis Label Plate) ที่อยู่ด้านข้างโหนด
- **ป้ายขนาดเล็ก (Size 2)**: ใช้ติดบนมือจับของโมดูลด้านหลังแชสซี เพื่อระบุข้อมูลของโมดูล I/O และ CMM
- **ข้อห้ามสำคัญ**: ห้ามติดป้ายลงบนหน้ากากของโหนดประมวลผลโดยตรง หรือติดในลักษณะที่ปิดกั้นช่องระบายอากาศของแชสซีเด็ดขาด

## 8. การอัปเดตเฟิร์มแวร์และไดรเวอร์อุปกรณ์ (Obtaining Firmware Updates & Device Drivers)

ชิ้นส่วนอุปกรณ์ที่สามารถอัปเดตเฟิร์มแวร์ได้ ได้แก่:
1. โมดูลการจัดการแชสซี (Chassis Management Module: CMM)
2. โหนดประมวลผล (Compute Nodes)
3. โมดูลอินพุต/เอาต์พุต (I/O Modules)
4. โหนดการจัดการ Flex System Manager (FSM)

### ไดรเวอร์อุปกรณ์ (Device Drivers)
ตัวควบคุมอีเทอร์เน็ต (Ethernet Controller) ถูกติดตั้งรวมมาบนบอร์ดของโหนดประมวลผล รองรับความเร็ว $1000\text{ Mbps Full-Duplex}$ ผู้ดูแลระบบไม่ต้องปรับจัมเปอร์บนบอร์ด แต่ต้องติดตั้งไดรเวอร์อุปกรณ์ลงในระบบปฏิบัติการของโหนดประมวลผลเพื่อให้มองเห็นและใช้งานการ์ดเครือข่ายได้

### ช่องทางการอัปเดตเฟิร์มแวร์
- **ผ่าน CMM**: ทำงานผ่านเว็บอินเทอร์เฟซของ CMM หรือใช้คำสั่งผ่าน Command-Line Interface (CLI `update` command)
- **ผ่าน Lenovo XClarity Administrator (LXCA)**: ดาวน์โหลด ติดตั้ง และจัดการเฟิร์มแวร์ตามนโยบายความสอดคล้อง (Compliance Policies) แต่ไม่สามารถอัปเดตไดรเวอร์ของ OS ได้
- **ผ่าน Flex System Manager (FSM)**: สามารถอัปเดตได้ทั้งเฟิร์มแวร์ของฮาร์ดแวร์และไดรเวอร์อุปกรณ์ของระบบปฏิบัติการ

> [!IMPORTANT]
> ต้องทำการอัปเดตเฟิร์มแวร์ของ CMM ให้เป็นเวอร์ชันล่าสุดเสมอ **ก่อนที่จะติดตั้งอุปกรณ์ชิ้นส่วนใหม่ๆ** เข้าสู่ Flex System Enterprise Chassis

## 9. ขั้นตอนการตัดการเชื่อมต่อระบบไฟฟ้าของแชสซีอย่างปลอดภัย (Disconnecting the Chassis from Power)

เนื่องจากแชสซีไม่มีสวิตช์ปิดไฟ การตัดไฟต้องทำตามลำดับขั้นตอนเพื่อป้องกันความเสียหายต่อข้อมูลและอุปกรณ์ฮาร์ดแวร์:

### ลำดับขั้นตอนการปิดระบบทีละขั้น (Graceful Shutdown Procedure)
1. **ปิดการทำงานของโหนดประมวลผลทุกตัว (Shut down each compute node)**: สั่งชัตดาวน์ระบบปฏิบัติการบนโหนดประมวลผลทุกตัวตามลำดับที่ถูกต้อง
2. **ปิดการทำงานของโหนดจัดเก็บข้อมูลทุกตัว (Shut down each storage node)**
3. **ปิดการทำงานของโหนดการจัดการ Flex System Manager (Shut down FSM)**:
   - หากใช้งาน FSM ในรูปแบบความพร้อมใช้งานสูง (HA: High-Availability) โหนดที่เป็น Active จะต้องทำกระบวนการสลับการทำงานด้วยมือ (Manual Failover) ไปยังโหนด Passive ก่อน จึงจะสั่งปิดการทำงานของโหนดได้
4. **ถอดสายไฟทั้งหมดที่ด้านหลังของแชสซีออกจากแหล่งจ่ายไฟภายนอก**

> [!IMPORTANT]
> หลังจากถอดสายไฟเพื่อตัดกระแสไฟฟ้าออกจากแชสซีแล้ว **ต้องรออย่างน้อย 5 วินาทีก่อนที่จะเสียบสายไฟกลับเข้าไปใหม่** เพื่อให้ประจุไฟฟ้าในวงจรคายออกจนหมด ป้องกันไฟกระชากที่อาจสร้างความเสียหายแก่อุปกรณ์อิเล็กทรอนิกส์ภายใน
