**ชื่องาน** ติดตั้ง Flex System Enterprise Chassis, Compute Node และคอนโซล KVM เข้าสู่ตู้แร็ค **อ้างอิง** CR-2569-001 **หน้าต่างเวลา** 14:30–17:00 น. 

เงื่อนไขยุติงาน Abort Criteria 

1. ถึงเวลา 16:00 น. แล้วยังติดตั้งตัวถังแชสซีเข้าตู้แร็คไม่สำเร็จ

เงื่อนไขยุติงาน Abort Criteria

1. ไม่สามารถเชื่อมต่อหรือเข้าถึง CMM ผ่าน HTTPS หรือ SSH ได้ หลังทดสอบใช้ปุ่ม Reset Button ทั้งแบบกดสั้นและกดค้าง 10 วินาที 
2. ไม่สามารถ Login เข้าสู่ระบบด้วย Default Credentials หลังทำ Factory Reset และไม่พบรหัสผ่านสำรอง 
3. เกิด IP Conflict บนระบบเครือข่าย VLAN 100 ที่ส่งผลกระทบต่ออุปกรณ์อื่นในตู้แร็ค 
4. ตรวจพบ Active Critical หรือ Error Event ใน CMM Event Log หรือไฟ Fault LED และ Check log LED สีเหลืองติดค้างบนแผงควบคุม Chassis ที่ไม่สามารถแก้ไขหรือคืนสภาพได้ภายใน 15 นาที 
5. Power Supply Unit แสดงไฟ Fault LED สีเหลือง หรือไฟ DC Out ดับ และการปลดสายไฟ AC เพื่อคายประจุ 5 วินาทีไม่สามารถแก้ไขได้ 
6. โมดูลพัดลมติดสภาวะ Fail-safe เร่งรอบ 100% เต็มกำลังต่อเนื่องแบบ Jet Air Noise และ CMM แจ้งเตือนสถานะการระบายความร้อนบกพร่อง Cooling Degraded 
7. ตรวจพบขาพินงอหรือชำรุด Bent Pins บนขั้วต่อ Connector ด้านหลังโหนด, I/O Module หรือบน Chassis Midplane
