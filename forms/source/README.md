## 2. กฎการนำข้อมูลไปลงในแบบฟอร์ม ISO/IEC 27001

1. **ไม่ดัดแปลงหัวตาราง (Table Schema Immutability)**: ห้ามเปลี่ยนชื่อคอลัมน์ เพิ่ม หรือลบคอลัมน์ในหัวตารางของแบบฟอร์มมาตรฐาน
2. **ไม่ยัดข้อมูลผิดวัตถุประสงค์ (Column Semantic Integrity)**: 
   - `ตำแหน่ง U`: ใส่เฉพาะตัวเลขตำแหน่งความสูง U จริง
   - `เหตุผลการจัดวาง`: ใส่เฉพาะเหตุผลเชิงกายภาพ เสถียรภาพ และทิศทางลมระบายความร้อน
   - `บริการที่รันอยู่`: ใส่เฉพาะบริการหลักหรือระบบปฏิบัติการ
   - `สเปกฮาร์ดแวร์และดิสก์ภายใน`: ใส่เฉพาะข้อมูลทางเทคนิคของฮาร์ดแวร์
3. **การจัดวางข้อมูลเสริม (Supplementary Placement)**: ข้อมูลแผนผัง IP, รหัสผ่าน SNMPv3, และการประเมินโหลดไฟฟ้าภาพรวมทั้งตู้แร็ค ให้ระบุไว้ในส่วนหมายเหตุท้ายตาราง (Engineering Notes) เสมอ
