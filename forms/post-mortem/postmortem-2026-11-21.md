## ส่วนที่ 1 — สรุปและผลกระทบ

| หัวข้อ | กรอกที่นี่ |
| :--- | :--- |
| สรุปสามประโยค | เครื่อง Proxmox VE Node 14 (`10.13.104.202`) หยุดตอบสนองนาน 58 ชั่วโมง 49 นาที หลังมีการเปลี่ยน Disk ให้กลุ่ม Blade (Bob และ Eve) ทำให้เครื่องค้างหน้า POST ของ RAID Controller และพบ error หน่วยความจำ `DIMM 21` ร่วมด้วย เหตุการณ์เกิดจากหลายปัจจัยร่วมกัน ได้แก่ การเปลี่ยนฮาร์ดดิสก์โดยไม่มีการจัดการ RAID และแจ้งเตือนล่วงหน้า ข้อจำกัดการกดผ่านหน้า POST ผ่าน Remote Control และไม่มีระบบ Alert แจ้งเตือน ปัจจุบันผู้ดูแลแก้ไขให้เปิดใช้งานเบื้องต้นได้แล้ว โดยยังชะลอการจัดสรรพื้นที่ให้ Disk ใหม่เพื่อลดความเสี่ยงต่อ Proxmox |

| ระดับความรุนแรง | SEV2 |
| หมายเลข Incident ที่เกี่ยวข้อง | INC-2026-1121-01 |
